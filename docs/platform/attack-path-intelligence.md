# Attack Path Intelligence

Attack path intelligence turns the context graph into prioritized, actionable
risk. Pacifics traces how an attacker could move from an entry point to a
high-value target.

## How paths are built

1. Identify entry points and exposures.
2. Traverse the graph along exploitable relationships.
3. Rank paths by reachability and the value of the target asset.

## Prioritization

Paths that reach sensitive assets with few hops rank highest. Remediating a
single hop can eliminate many paths at once.
