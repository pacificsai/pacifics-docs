# Security Context Graph

The security context graph is the foundation of Pacifics. It unifies assets,
identities, configurations, and relationships from every connected environment
into a single queryable model.

## What the graph captures

- **Assets** — workloads, data stores, and services.
- **Identities** — users, roles, and service principals.
- **Relationships** — permissions, network reachability, and trust.

## Why it matters

Isolated findings miss context. The graph connects them so Pacifics can reason
about how a weakness in one place enables an attack somewhere else.
