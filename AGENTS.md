# AGENTS.md

Context for AI coding agents working in this repository.

## Project

Pacifics documentation site. Pacifics is an AI-powered cybersecurity
intelligence platform (Security Context Graph + Attack Path Intelligence +
Controlled AI). This repo holds the docs, built with Docusaurus 3 and
TypeScript.

## Stack

- Docusaurus 3.x (`@docusaurus/preset-classic`, `@docusaurus/faster`)
- React 19, TypeScript
- Node >= 20

## Layout

- `docs/` — documentation content, organized by category:
  - `getting-started/`, `platform/`, `guides/`, `integrations/`, `api/`, `resources/`
  - each category folder has a `_category_.json` controlling sidebar label/position
- `src/pages/` — custom pages (e.g. the homepage `index.tsx`)
- `src/components/` — React components used by pages
- `src/css/custom.css` — theme overrides
- `static/img/` — images and assets
- `docusaurus.config.ts` — site config (title, navbar, footer, plugins)
- `sidebars.ts` — sidebar config (autogenerated from `docs/`)

## Commands

- `npm run start` — local dev server (do not run in automation; it is long-running)
- `npm run build` — production build; **fails on broken links** (`onBrokenLinks: 'throw'`)
- `npm run serve` — serve a built site
- `npm run typecheck` — TypeScript check

## Conventions

- Add docs as `.md`/`.mdx` under the right category folder.
- Use frontmatter `sidebar_position` to order pages.
- Prefer relative links between docs so broken-link checks pass.
- The blog is disabled (`blog: false`); do not add blog links.

## Verification

Always run `npm run build` after doc or config changes to confirm there are no
broken links or build errors before considering the work done.
