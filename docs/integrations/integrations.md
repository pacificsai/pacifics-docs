# Integrations

Pacifics ingests data from the environments you connect. Each integration uses
read-only access and feeds the security context graph.

## Available integrations

| Category | Providers |
| --- | --- |
| Cloud | AWS, Azure, GCP |
| Identity | Okta, Entra ID |
| Source control | GitHub, GitLab |

## Connecting

1. Go to **Settings → Integrations**.
2. Select a provider and complete the authorization flow.
3. Grant the recommended permissions.
4. Start the initial sync.

See [Connect your environment](../getting-started/connect-environment.md) for a
step-by-step walkthrough.
