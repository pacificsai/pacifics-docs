# Connect Your Environment

Pacifics builds its context graph from the environments you connect. Start with
one source and add more over time.

## Supported sources

- Cloud providers (AWS, Azure, GCP)
- Identity providers
- Source control and CI/CD

## Connect a source

1. Go to **Settings → Integrations**.
2. Choose a provider and follow the authorization flow.
3. Grant the recommended read-only permissions.
4. Confirm the connection and start the initial sync.

See [Integrations](../integrations/integrations.md) for the full list and
required permissions.
