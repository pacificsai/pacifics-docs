# Introduction

Pacifics is a security context graph and attack-path intelligence platform. It
connects your cloud, identity, and workload data into a single graph, then uses
AI reasoning to surface the attack paths that matter most.

## What you can do

- Build a unified security context graph across your environments.
- Discover and prioritize real, exploitable attack paths.
- Investigate findings with AI-assisted reasoning.
