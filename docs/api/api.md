# API Overview

The Pacifics API provides programmatic access to your security context graph,
findings, and attack paths.

## Base URL

```
https://api.pacifics.in/v1
```

## Conventions

- JSON request and response bodies.
- Standard HTTP status codes.
- Cursor-based pagination on list endpoints.

## Authentication

All requests require an API token. See [Authentication](./authentication.md).
