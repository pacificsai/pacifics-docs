# AI Security Reasoning

Pacifics applies AI reasoning on top of the context graph to explain findings,
summarize attack paths, and recommend remediation.

## What it does

- Explains why a path is exploitable in plain language.
- Summarizes root cause across multiple findings.
- Suggests the most effective remediation to break a path.

## Working with the AI

Reasoning is grounded in your graph data, so answers reflect your actual
environment. See [Investigate with AI](../guides/investigate-with-ai.md).
