# Your First Attack Path

Once your environment is connected and the graph is built, Pacifics surfaces
attack paths — chains of findings that an attacker could use to reach a
sensitive asset.

## Read an attack path

1. Open the **Attack Paths** view.
2. Select a path to see each hop from entry point to target.
3. Inspect the context behind each hop in the graph.

## Act on it

- Prioritize paths that reach high-value assets.
- Use [AI investigation](../guides/investigate-with-ai.md) to understand root cause.
- Break the path by remediating any single hop.
