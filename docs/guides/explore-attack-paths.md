# Explore Attack Paths

Navigate and filter attack paths to focus on what matters.

## Steps

1. Open the **Attack Paths** view.
2. Filter by target asset, severity, or environment.
3. Select a path to inspect each hop.
4. Drill into the graph to see the surrounding context.

## Act on findings

- Prioritize paths reaching high-value assets.
- Identify shared hops that, once fixed, break multiple paths.
